# 使用手册

## 角色

| 角色 | 能力 |
|---|---|
| 游客 | 浏览推荐站点、搜索、查看用户协议、注册 |
| 成员（普通用户） | 自己的面板：分组/卡片全套管理、个人设置、导出 |
| 管理员 | 成员能力 + 用户管理、站点设置、服务器监控、Docker 管理、整库备份 |

## 游客首页

- **搜索框**：输入关键词回车跳转所选引擎；直接输入网址（如 `example.com`）回车直达；引擎可切换且被记住
- **推荐面板**：中文/英文两套常用站点（按界面语言显示），点击直达
- 右上角「注册」进入注册页（用户名 + 密码 + 可选邮箱 + 勾选用户协议）；注册开关关闭时仅显示提示

## 成员面板

### 分组与卡片
- **新建分组 / 添加卡片**：编辑模式下点对应按钮
- **编辑模式**：点 ✎ 进入/退出；进入后可拖拽排序、跨组移动卡片、拖分组标题调分组顺序、键盘 ↑↓ 微调选中卡片
- **卡片编辑弹窗**：所属分组、名称、外网网址（必填）、内网地址（选填，内外网切换用）、图标、备注
- **移动端**：长按卡片呼出操作菜单（编辑 / iframe 预览 / 删除）；拖拽整理同样可用

### 内外网切换 🌐
- 卡片配了内网地址后，顶栏 🌐 按钮在「自动 / 内网 / 外网」间循环切换，**免刷新**改写所有双地址卡片
- 自动模式按站点内网网段判定你的来源；按钮悬停有当前判定说明

### 搜索
- 关键词回车走引擎；输入网址回车直达；引擎切换即时生效并记住

### 个人设置（⚙）
- 面板标题、壁纸（预设渐变 / URL / 上传 ≤8MB）、搜索引擎、修改密码

### 数据导出
- 面板头部「编辑模式」旁的导出入口：CSV（表格）或 Netscape HTML（可导入浏览器书签）

## 管理后台（管理员）

入口：👤 菜单 → 🔧 系统管理（或直接访问 `admin.php`）。

| 标签 | 内容 |
|---|---|
| 用户管理 | 用户列表、新建用户（指定角色）、重置密码、禁用/启用、删除 |
| 个人设置 | 与成员相同的个人设置 |
| 站点设置 | 站点名称（中/英）、界面语言、开放注册、内网网段、状态条开关、SMTP 与邮箱验证码 |
| 服务器 | CPU/内存/磁盘/网速/负载/运行时长实时监控；Docker 容器列表与启停重启（需挂载 sock）；备份导出/导入；清图标缓存 |

## 键盘与手势速查

| 操作 | 方式 |
|---|---|
| 卡片上移/下移 | 编辑模式选中后 ↑ / ↓ |
| 拖拽排序 | 编辑模式下拖卡片 / 拖分组标题 |
| 移动端编辑 | 长按卡片 |
| 搜索直达网址 | 输入域名回车 |
